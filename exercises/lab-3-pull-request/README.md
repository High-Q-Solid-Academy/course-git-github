# Lab 3: Opening an Inspected Pull Request

## 🎯 Goal
Push your work to GitHub and open a Pull Request (PR) with proper documentation and conventional commit standards.

## 📋 Task Instructions
1. Create a new branch named `submission/final-git-project`:
   ```bash
   git checkout -b submission/final-git-project
   ```
2. Create a file `student-reflection.md` in this directory. Write 3 key things you learned about Git.
3. Commit using a conventional commit message:
   ```bash
   git add exercises/lab-3-pull-request/student-reflection.md
   git commit -m "docs: add git reflection document"
   ```
4. Push your branch to GitHub:
   ```bash
   git push -u origin submission/final-git-project
   ```
5. Navigate to your repository on GitHub.
6. Click **Compare & Pull Request**.
7. Complete all the checklist items in the High Q Pull Request template.
8. Watch the GitHub Actions autograding workflow run and turn green!
