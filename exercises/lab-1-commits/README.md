# Lab 1: Your First Clean Commits

## 🎯 Goal
Learn how to create, stage, and commit changes using **Conventional Commits**.

## 📋 Task Instructions
1. Open the file `student-profile.md` located in this folder.
2. Fill in your details (Full Name, High Q Student ID / Email, and your tech goals).
3. Stage the file using the Git CLI:
   ```bash
   git add exercises/lab-1-commits/student-profile.md
   ```
4. Commit your changes with a conventional commit message:
   ```bash
   git commit -m "feat: add student profile for Lab 1"
   ```
5. Check your log history:
   ```bash
   git log -1
   ```
